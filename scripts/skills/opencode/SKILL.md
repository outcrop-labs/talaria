# OpenCode is not offered

This agent does not run OpenCode. Coding work goes through the workbench
(**workbench-driving**): `doctor`, `start_job`, drive **Oh My Pi**
(the `oh-my-pi` skill), `finish_job`.

Do not `npx` OpenCode. Do not hand-code around a missing harness; that is
`report_gap`.
