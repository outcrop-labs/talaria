# X / Twitter (Talaria)

There is no sanctioned agent path to post, DM, or scrape X. `xurl` is not
installed and must not be. If a task needs a public post, that is
`report_gap` — a human posts, or the org connects a governed tool.

Never store an X token. Never impersonate the company on a social network
from this container.
