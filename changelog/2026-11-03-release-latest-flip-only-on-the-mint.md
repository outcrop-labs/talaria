- **Fixed: the guard that keeps a server release off GitHub's "Latest" now also requires the desktop feed flip to run only on the mint path, and the macOS installer smoke can no longer hang the release on an app that ignores SIGTERM.** #661's review found two gaps. First, `scripts/release-latest.mjs` checked that desktop-package.yml's `gh release edit --latest` came after the `latest.json` upload, but not that it ran only for a minted `desktop-v` release. `attach` also runs for release.yml's `vX.Y.Z` tags, so dropping `if [ "$MINT" = true ]` would have kept `bun run check` green and made the stable server release Latest. The flip must now sit in the `then` branch of a shell `if` that tests `"$MINT" = true` (an `&&` is fine, an `||` is not), or under a step `if:` on `needs.resolve.outputs.mint`, and its step must bind `MINT` to that output. Second, the macOS step stopped the 20 s run with `kill` and then waited for it with no limit, so an app that ignored SIGTERM would have held the job until its 60-minute timeout. It now polls with `kill -0` for up to 10 s, then sends SIGKILL. Every installer smoke step also gets a step timeout (5 to 15 minutes), which bounds the older `Start-Process -Wait` waits on Windows as well. The Linux step's comment no longer claims the deb's Depends are proved to resolve on a stock Ubuntu: the build's own -dev packages already satisfy them.

  Verified: `release-latest.mjs`'s self-test has 8 new fixtures, and it fails on each of these: a flip with its `MINT` guard removed, a flip in the guard's `else` branch, a flip guarded by another test, one guarded by an `||` test, a step that sets `MINT: 'true'`, and an unguarded flip after an unrelated `if … fi`. It passes an `&&` guard and a step-level mint `if:`. On the real desktop-package.yml, `check-invariants.mjs` passes. It fails and names line 916 when the real `if [ "$MINT" = true ]` is removed, and line 917 when the step sets `MINT: 'true'`. The kill sequence, run against a process that traps SIGTERM, ends it in 12 s, and a process that honours SIGTERM goes at once. desktop-package.yml parses (Bun's YAML), every bash step passes `bash -n`, and the five step timeouts land on the intended steps.
