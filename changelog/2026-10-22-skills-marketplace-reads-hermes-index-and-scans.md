- **Changed:** the skills marketplace reads Hermes' own official skills index and runs Hermes' Skills Guard before every install; the toolset switches are now exactly Hermes' own, and a skill's frontmatter description is what the library shows. The marketplace used to scrape a third-party site's HTML for a ranked list of repos, then download a whole repo tarball (any `owner/repo`, for any member) and write every SKILL.md in it unscanned into roots every agent loads. Now the `skills-index-refresh` job mirrors Hermes' `skills-index.json` (the index Hermes' own skills search reads, rebuilt daily) into `skills_index_entries` every six hours. It keeps the ~20k rows Talaria can install (Hermes' official optional skills, its curated GitHub taps, skills.sh) and sends the last ETag, so most runs are a 304. The picker searches that table, one card per skill, with Hermes' trust level on each. Install takes a catalog id only. It fetches that one skill directory from GitHub at a pinned commit (two API calls, then raw files; never the repo, which runs to 245 MB for some catalog skills). It follows an official catalog stub to its upstream repo and judges it as trusted, which is what Hermes says it intends. Then it runs Hermes' unmodified `scan_skill` and `should_allow_install` in a one-shot `docker run` of the fleet's own Hermes image: no network, read-only, all capabilities dropped, as nobody. A blocked skill is a 422 carrying the report and nothing is written. The fetch-and-scan route (`detail`) now needs `owner` and edit rights there, and only serves catalog ids. Unrelated: `GOVERNED_TOOLSETS` drops the composites `safe`, `debugging` and `search`, the `coding` posture, and the GUI-only `project` and `desktop_ui`. Closing a composite closed its member tools while their rows read open, and the others closed nothing. A stored, org-floor, env or API-supplied retired name expands to the governed toolsets it closed (`search` reads as the stricter `web`), and a migration rewrites stored rows the same way. `scripts/hermes-toolsets.json` snapshots Hermes' `CONFIGURABLE_TOOLSETS`: a cargo test holds the list to it, and the chassis smoke holds it to the live image. The skill library serves a frontmatter `description:` as written, parsed the way Hermes parses it, and asks the summarizer only about skills that have none.
