- **Changed: a live ticket shows what its agent is doing now, on the board and in the ticket.** A work session used to say `turn 2 of 12 — waiting on doug-engineering` from the moment the turn was sent until it ended. On the owner's instance that was the same for a session forty minutes into a build and one its agent had not started, and the ticket strip printed the turn twice. Each watch-tail frame is now stamped with its arrival time, and each turn records when it began. The ticket and board reads return the session's live status: whether it is running a step, thinking, quiet, or still waiting for the agent to take the turn; the step and how long it has run; the last output or sentence; recent failures with the last one's text; and the tokens and cost booked to the ticket since the session started. When no tokens are booked to the ticket, the reads say why: the agent's Hermes does not tag calls with the session, or the agent still runs on the shared fleet key and needs a roll. Board cards and list rows show the same in two lines. A queued ticket names the tickets it waits behind. A failed session's row in the Work log shows why it ended. A workbench job shows its provisioning state and error when the job read carries them. Everything comes from the server, so a refresh or a second tab shows the same.

  Verified: unit tests for the tail reader cover the shapes on the owner's instance: a terminal call inside an execute_code cell, a build killed at the 420-second ceiling, the events plugin reporting a call before the stream does, a plugin-only tail, a cut window, and a refused workbench tool. Unit tests also cover the state word and the labels; `svelte-check` reports 0 errors. On a worktree stack with a real Hermes v0.22.4 Developer Agent and a mock model, the board read and the screenshots of three live tickets show each one `running` with its own shell step and clock, 5.3k tokens booked to each ticket, and `quiet` with its age while the agent took minutes to start a turn. After a failed turn the Work log row showed the session's error.
