- **Added:** The org-wide toolset floor is now an admin setting with an editor, not a row set by SQL. `PUT /api/admin/settings` takes `mandatoryDisabledToolsets`, a list of governed Hermes toolset names: trimmed, deduped and sorted on the way in, `todo` and `clarify` implied and never stored, and a name outside the governed vocabulary refused with a 400 that names every stranger in the list (`unknown toolsets "brower", "discord"`), not just the first. The GET answers the stored floor beside `toolsets` (the governed names, the builtin pair, and anything `TALARIA_MANDATORY_DISABLED_TOOLSETS` pins), so the panel cannot offer a name the write would refuse. The write audits as `settings.toolset_floor` with before and after, and rolls nothing: the renderer reads the key on every render, so the floor lands on each agent at its next render or roll, which is what the panel says when it saves. The editor is **Admin → Security → Agent toolsets**: the agent editor's own grid over the whole fleet, the builtin pair and the env-pinned names locked with their reason. `GET /api/fleet/defs` now answers `toolsets.mandatoryDisabled` as the whole floor (the pair plus the org floor) and adds `toolsets.orgDisabled` for the org part alone, so the agent toolset editor locks an org-closed row with "closed org-wide by an admin" rather than the pair's reason; an org-closed name a manager had stored stays stored, so lifting the floor later gives each agent back exactly what its managers chose. `docs/user/admin-agents.md` describes the toolset grid and the floor. Verified: `cargo test -p talaria-routes-admin --lib admin_settings` (the stored spelling, every stranger named, the body grammar, the vocabulary); `cargo test -p talaria-routes-fleet --lib fleet_defs` (the floor rides whole and the org part alone); `cargo clippy -p talaria-routes-admin -p talaria-routes-fleet --tests -- -D warnings`; `bunx vitest run src/components/fleet/toolsets.test.ts` (an org-closed row is locked with its own reason; `builtinFloor` keeps an org-closed name in the stored list); `bun run typecheck`; `bun run docs:api`; `bun run check`.
