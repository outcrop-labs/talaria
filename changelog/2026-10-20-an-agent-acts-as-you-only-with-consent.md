- **Changed:** Pointing an agent at another person's Google account is an admin's call. `PUT /api/fleet/defs/{id}/google` with `principalKind: owner` and a `principalUserId` that is not the caller now answers 403 unless the caller is an admin; an agent's manager can still bind it to their own account. Either way the person named is notified in-app — which agent, pointed by whom, and where to undo it — beside the audit row the route already wrote. Connecting an agent's own Google account records the manager who did it (`connected_by`) and writes an `agent.google_connect` audit row; connecting the shared org account writes `google.org_connect`. `docs/GOOGLE-WORKSPACE.md` now lists the scopes the code actually requests (`openid`, `email`, full `drive`, `calendar.events`, `gmail.modify`, `gmail.send`; full `calendar` and `drive` for the org connect) instead of the retired `drive.file` / `drive.readonly` / `gmail.readonly` set.
