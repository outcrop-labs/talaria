- **Changed:** A work session's pane shows the session's files, not a plan document. Every Talaria document, sheet or page and every Google file the agent creates or opens in the session is a tab, read from `GET /api/conversations/{id}/files` and re-read on every landed turn and every finished write tool (the Google writers included); a file that is new, or that a newer message touched again, opens and takes the pane, newest touch first. A session opens on the tab you were reading last time, else the file touched most recently, else the first. Opening a session creates nothing: no "Document" tab that would not close, no "Plan document" row, no Sync from chat, no Auto-saves label. Each file has one header row for every type (type label, title, Read/Edit, comments, Open ↗, fullscreen, More, close): the artifact editor's own toolbar folds into it, with share and official moved into More, and a Google file embeds without a second title row. Closing a tab hides that file for you in that session until the agent touches it again, or until you reopen it from "All files (N)" at the end of the strip. An empty session says "Nothing open yet" and offers New document and Open a Google file, and a pasted Google link is now appended to the session's pinned files instead of replacing them. The open file goes out with every work turn as the chat body's `focus`, so "this doc" names the file in front of you. The header loses the zero-state plan template picker; Research, Export, Schedule and Draft tickets sit in one quiet icon-and-label group, Rename, Archive and Delete move behind a `⋯` menu, and the narrow-screen toggle reads Chat / Files. Plan sessions keep their living document, now headed "Plan", with Sync from chat, comments, and Draft tickets as the gold primary.
