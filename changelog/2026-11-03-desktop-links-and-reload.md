- **Fixed: in Talaria Desktop, links that open a new window now go somewhere, and an instance page can be reloaded.** Before this, a `target="_blank"` link or a `window.open` inside an instance did nothing on every OS: wry drops a new-window request when the shell installs no handler, and none was installed. That covered a Google Drive file, a GitHub settings page, a web source in chat, the coding-harness sign-in link and the MCP Connect button. Now each kind of link goes to its own place. A link to another site opens in the default browser. A popup on the instance's own origin opens as an in-app window that keeps the instance's session and `window.opener`, which the MCP connect needs to sign in and report back; its window closes when the connect finishes. `mailto:`, `tel:` and app links (`zoommtg:`, `slack:`…) go to the OS, whether they open a window or navigate in place. On Linux an in-place `mailto:` did nothing before. `file:`, `javascript:` and `data:` windows and the schemes browsers never hand the OS (`ms-msdt:`, `search-ms:`, `shell:`, remote shares) are refused. The hand-off goes through `tauri-plugin-opener`'s `open_url` on a background thread; the plugin is not registered, so no page gets an opener command. Reload had no way in at all. Ctrl+R and F5 on Windows and Linux, and Cmd+R on macOS, now reload any instance page; add Shift (or press Ctrl+F5) to skip the cache. The keys are the shell's own script, so they also work on a page whose Talaria UI never loaded, such as a gateway's 502 page. The in-app instance switcher has **Reload page** with its shortcut, and on macOS the menu bar has **View → Reload Page** and **Reload Ignoring Cache**.
  Verified: on a private headless rig (its own mutter, session bus and two fake instances), with real clicks and key presses through mutter's RemoteDesktop. Every launcher the opener tries was replaced by a shim that records its arguments and opens nothing. On rc's build, every link class did nothing: no shim call, no request, the page unchanged, and the Connect popup's `window.open` returned null. No key reloaded anything, and `desktop_reload` did not exist. On this build: three cross-origin links (`target="_blank"`, `window.open`, and `window.open(…, 'noopener,noreferrer')`) each reached `xdg-open` with their URL, and the instance page stayed. An in-place `mailto:`, a `target="_blank"` `mailto:`, a `tel:` and an in-place `zoommtg:` each reached `xdg-open`. `javascript:`, `data:`, `ms-msdt:` and `file:` windows opened nothing, and the first three were logged as refused. The MCP-style connect popup ran its whole round trip with the instance's session cookie: own origin, then another origin's authorize hop, then the callback's `postMessage` to the opener, which received it. Its window then closed (mutter unmanaged it 1.2 s after the message). Before the window fix, the empty window stayed until Talaria quit. A same-origin `target="_blank"` page opened in-app with the session. Ctrl+R, F5 and the switcher's command each reloaded the page, and Ctrl+Shift+R, Shift+F5 and Ctrl+F5 reloaded it with `Cache-Control: no-cache`. Super+R and Ctrl+Alt+R did nothing. On a 502 page from the instance's origin, F5, Ctrl+R and Ctrl+Shift+R reloaded it. On another origin's 502 page, which has no grant, F5 reloaded it through the page's own fallback. `scripts/desktop-reload-keys.mjs` (in `bun run check`) presses every key on Linux, Windows and macOS user agents; it fails on six mutations of the script. New tests cover the link routing (Rust) and the switcher menu (ui); `bun run check` passes, including the webview-threading rule. Desktop fmt, clippy `-D warnings` and the tests pass in the rig image. Not verified on Windows or macOS at run time: the WebView2 and WKWebView popups, the hand-off through ShellExecute and `open`, the macOS View menu, and macOS's cache-skipping reload. On macOS a self-closing popup's window likely stays open until closed by hand. Also not verified: an installed release build, an AppImage's environment reaching the browser it launches, and a real MCP provider's sign-in.
