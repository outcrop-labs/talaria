- **CI runs on a plain push to `ci/<branch>` — no pull request — and one planner decides what CI and `bun run gate` check.** A new workflow, `CI offload`, calls `ci.yml` for every push to `ci/**`, so an agent can have GitHub's runners compile and test a branch instead of its own machine. Its checks are named `offload / …`, so they can never satisfy or shadow a required check, and a daily job deletes `ci/**` refs whose tip is more than a day old.

  `scripts/surfaces.mjs` now holds the surface lists that lived twice, as bash in `ci.yml` and as a copy in `scripts/gate.mjs`. It also picks the run's mode and diff range:
  - **light**: a pull request into anything but rc or main, or a push to `ci/<branch>`. Linux jobs only; macOS, Windows, iOS and e2e are skipped.
  - **full**: a pull request into rc or main, a push to rc or main, a release, `ci/full/<branch>`, or the offload of a `hotfix/`, `release/`, `sync/`, `promote/` or `backflow/` branch.
  - **integration**: a push to `testing`, ready for when that branch returns.

  A pull request diffs its merge commit against the base tip it was built on, and the checkout now takes the event's own commit. Re-reading `refs/pull/N/merge` by name is how a changelog-only pull request once ran every job. A push to rc or main checks everything since that branch's last green run, so a cancelled or red run is covered by the next one. Pushes to long-lived branches queue instead of cancelling each other. Only those pushes write the Rust cache, which was over GitHub's 10 GB cap. A pull request is planned by its base's copy of the planner, so it cannot narrow its own CI. When the plan is missing a value, that surface runs.

  `bun run gate` diffs against the nearer of `origin/testing` and `origin/rc`. It exits 2 with `gate: base` or `gate: red — <command>` as its first stderr line. `bun run check` now finds every `scripts/*.test.mjs` itself. A new invariant, `ci-call-grants`, fails any workflow that calls `ci.yml` without granting `actions: read`. A caller like that dies at startup with no job run, as the September nightlies did.
