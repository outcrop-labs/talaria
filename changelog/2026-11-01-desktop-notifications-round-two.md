- **Desktop notifications, round two: every signed-in instance alerts, a read anywhere clears the banner, the dock badge counts what is for you, and the dock's Quit quits on Linux.** Instances you are signed in to but have not opened this session are now loaded hidden at launch (one second in, then five seconds apart, five at most) and handed to the shell's own watcher, so their DMs and mentions banner without a click, as Slack and Teams do for every workspace. The watcher speaks the notification contract: with an instance that serves it, it reads `?since=` its own cursor page by page and reopens its stream with `?since=`, so a reconnect after an outage or a sleep is exact rather than "the newest 50"; it never banners a row the server marked `feed`; while your Do Not Disturb is on it banners only what breaks through (approvals and other needs-you kinds); it acks every row it banners, so the instance's deferred push for it is cancelled; it heartbeats your presence as this desktop (`active` while the OS saw input in the last two minutes), so the instance can hold a push while you are at the desktop; and its catch-up summary carries the page's own tag, `talaria-summary`, so clicking it restores the instance and opens the bell. When a notification is read anywhere else, the banner closes: the watcher closes its own from the stream, and instance pages can close theirs through a new `desktop_notify_close` command (GNOME's `CloseNotification`; macOS removes it from Notification Center too), keyed by the calling instance so one instance can never close another's. A new `desktop_os_idle` command reports the OS idle time (mutter's idle monitor on GNOME, the screensaver service on KDE/X11, CoreGraphics on macOS) for presence. The dock and launcher badge, the launcher's per-instance count and the tray now count For you — what needs you and what is addressed to you — not everything unread; the tray menu lists each instance with its own count ("Acme — 3"), which drops when you read, and opens it on a click. Each instance's row in the launcher has a bell that mutes its banners on this desktop (its count still shows), and Settings → Desktop says when an instance is muted. On Linux the GTK application is now registered as `app.talaria.desktop` with a real `quit` action, so GNOME's dash and Alt+Tab Quit actually quit Talaria (every page remembered) instead of only closing the window; the window's Wayland app_id and X11 class are `app.talaria.desktop`, and the deb and rpm `Talaria.desktop` names it (`StartupWMClass`) without being renamed, so pins keep working. The deb and the rpm now recommend the tray library instead of requiring it (Talaria runs without it and minimizes on close). The macOS menu-bar item is a template image that follows the menu bar's light and dark look, and a left click shows its menu. Windows is unchanged this round.
