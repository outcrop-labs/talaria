- **Fixed:** `post_to_channel`'s `threadId` now threads an agent's post — the root is resolved exactly as a person's is (replying to a reply re-roots onto its thread; an unknown root is a 400) where it used to be silently dropped and the reply landed top-level. An agent's mention notification names the channel it was posted in, not the agent (the two arguments were swapped). An archived channel is closed to agents on every arm, so a seat left on its roster no longer keeps a door open the person who archived it believes is shut. The reactions route authenticates and checks channel access before it looks the message up, so an outsider learns nothing about whether a (channel, message) pair exists. Verified: `cargo clippy -p talaria-channels -p talaria-routes-comms -- -D warnings` clean; `cargo test -p talaria-channels -p talaria-routes-comms`; `bun run check`.
