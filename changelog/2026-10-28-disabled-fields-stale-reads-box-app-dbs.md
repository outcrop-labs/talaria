- **Fixed: a disabled field looks disabled, the agent roster and the memory's Whole file view no longer stick on skeletons, and a devbox's app can open its app databases.**
  - **F23.** The `Input`, `Textarea` and `Select` primitives had no disabled state, so a viewer's task title, a field held during a save and a setting switched off all drew like fields that took typing. They take `disabledControl` (`components/ui/control.ts`): the shared `dimDisabled` plus a not-allowed cursor. Combobox's trigger and the chat chrome's rail chips draw the same string.
  - **F17.** svelte-query passes a change to a component only when it touches a prop the component has already read. The roster gated on `defs.isLoading || containers.isLoading`, which never read the containers' flag while defs loaded, and its banner had already read the containers' `isError`. So when `/api/fleet/containers` answered first, the later read of `isLoading` got the value from before the answer, and the roster kept its skeletons for good. `anyLoading` / `anyPending` (`components/ui/query-state.ts`) read every flag before combining. The roster and the four other two-query gates (the boards sublist, Models → Roles and Access, Artifacts) go through them, and a unit test fails any new `a.isLoading || b.isLoading`. The same stale read held the agent memory's **Whole file** view on its skeleton whenever the read landed while **Entries** was showing, for fleet agents and the personal assistant: `useMemory` now notifies on every change.
  - **F21.** Inside a devbox the app dialled an app database at `127.0.0.1:<published port>`, the box container's own loopback, so no app's store could open. The box compose sets `TALARIA_APP_DB_NETWORK` to the box's own network: the app DB joins it with no published port, and the app dials it by container name. `TALARIA_DEVBOX` carries the box's name instead of `1`, so two boxes running one app get two databases. An app DB's compose service is named for its container, not `postgres`: compose aliases a service by its name on every network it joins, and on the box's network (and the image's `internal`) `postgres` is the platform's own database. `talaria box rm` removes the box's app databases and empties the box's state from a root container, since an app database owns its files and the removal used to die on them with EACCES. A host-run app dials the loopback port as before.
