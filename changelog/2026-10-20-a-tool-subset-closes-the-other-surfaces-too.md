- **Changed:** An agent holding a tool subset on an MCP server is now refused `resources/*`, `prompts/*` and `completion/*` with JSON-RPC `-32601`, and each refusal is recorded in the call record under the request's own method. A subset is an admin's statement about what the agent may reach, and those surfaces relayed with the injected credential and no tool name for the gate to read — so an agent narrowed to one tool could still read every resource the server exposed, unrecorded. An agent with no subset keeps today's relay; `initialize`, `ping`, notifications and the tool methods are unaffected. Documented under "Enforcement: the gateway" in `docs/MCP.md`. Verified: `cargo test -p talaria-routes-fleet --lib mcp_gw_server` (each closed method is refused with -32601 under a subset and relays without one; protocol chatter and the tool methods pass); `cargo test -p talaria-mcp --lib calls::` (a refused method begins a log under its own method, capped like a tool name; a tools/call still records as `tools/call`); clippy `-D warnings`; `bun run check` (its invariant pass reports three failures, all in files this change does not touch: a hand-unwrapped secretbox in `fleet_defs_id_rotate_key.rs`, an off-board status literal in `mcp/src/index.ts`, and duplicate `too_many_requests`/`agent_brake` bodies in the knowledge and comms route crates).
