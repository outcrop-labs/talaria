The guard that talaria-chat-persist ran on the stream is deleted. The person's own stop and steer, and the work-session thrash brake, are unchanged. (2) A turn's effort pick now travels as `model_options.reasoning_effort` on both persona arms. Hermes' API server ignores a top-level `reasoning_effort`, so every pick and every configured default ran at Hermes' `medium`, and the session arm carried no effort at all. The render writes each model's configured, vouched effort as `agent.reasoning_overrides`. It marks a model with no vouched levels `model_overrides.custom.<id>.supports_reasoning: false`, so Hermes sends no effort for it instead of filling in `medium`. The persona transports (Rust and the TS twin) no longer send `temperature` or `response_format`, which Hermes never reads. A JSON request to a persona now comes back `contract_dropped`, so the runner relies on its prompt anchor, the way it does on a gateway that strips the parameter. Without the route, a tier turn on the completions arm ran the main model and was metered as the tier.
