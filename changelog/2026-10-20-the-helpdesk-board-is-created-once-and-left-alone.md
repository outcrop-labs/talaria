- **Fixed:** `report_problem` no longer rewrites a board. It used to find ANY live board named "Helpdesk" — a team's private one included — and on every call make it org-wide, move it to the Talaria team, join every user as editor and reset its agent policy. The Helpdesk board is now resolved by its stored id (`app_settings.helpdesk_board_id`), created exactly once — org-wide, on the Talaria team, open to every agent — and never written to again, so an admin's membership removals and agent restrictions stand; a stored board that was archived or deleted is replaced by a fresh one rather than resurrected. The route is braked at ten reports per agent per hour (429 with Retry-After, the house error shape), and the same agent reporting the same summary within a day is acknowledged — `duplicate: true`, a relay sentence — without a second ticket or a second round of admin notifications, the posture `report_gap` has always had. Verified: `cargo clippy -p talaria-routes-fleet -- -D warnings` clean; `cargo test -p talaria-routes-fleet`; `bun run check`.
