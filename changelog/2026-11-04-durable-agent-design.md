- **Changed: an agent design is the server's, so a reload, a closed tab, another tab or a restart no longer loses it. New agent resumes where the design stands, and a design that finishes while you are away rings the bell.** "Describe it" used to run inside the browser: the page awaited the muse call itself and held the chat, the draft and the elapsed count in memory. Now a describe or a refine is an `agent-design` run on the runs runtime (`talaria-agent-design`). The record lives in Redis for 72 hours: the instruction and chat, the validated draft, the status, the error, and the start and finish times. Any api process can serve it, and a process that dies mid-design is reclaimed. `/api/fleet/agent-design` reads (GET), starts or refines (POST), saves the person's edits (PATCH) and discards (DELETE), all under `agents.manage`. A hire that names the design (`designId` on `/api/fleet/create`) claims it first, so two tabs cannot hire two agents from one design. The design is used up when that hire finishes. The design leaves New agent as the hire starts, so you can design the next agent while it runs. It is used up once the hire has created the agent, whatever fails after that (a download, a boot): the hiring strip's **Retry** or the agent's **Start** finishes those. A hire that fails before the agent exists (a department taken in a race, say) hands the design back with its reason. It goes onto the review step when New agent is empty. If you have started another design meanwhile, it waits and never overwrites that one: the bell says "The hire of <name> did not finish", New agent shows a line about it with **Discard it**, and the design comes back once the open one is hired or discarded. A **Retry** on the hiring strip takes the design along, so it is used up when the retried hire finishes. There is still one design per person: a describe while one is generating returns that one, and a describe over an idle design replaces it. Opening New agent shows the splash with the time since the server started, or the review step. Hand edits are saved as you type. An edit made just before you close the modal is saved as an ordinary save, at any size. One made just before the page closes rides a `keepalive` save, which browsers cap at 64 KiB. A larger edit (a long soul) sends its small fields, or nothing if even those over the saved soul are too big. The edit itself is kept in this browser for this person and offered back once, when New agent next opens on that design, unless the design has been saved since. It is never reported as saved. Signing out clears it. A Create that meets a newer design (another tab) stops and shows the current one. Each save and refine names the design it edits, so a tab that missed a discard elsewhere is refused and shown the current design, never written over it. **Duplicate** opens its own form and leaves a waiting design alone. **Discard design** stops a design that is running and throws it away. A design that lands with no modal open on it (none for the last 12 seconds) files an **Agent design ready** (or **The agent design failed**) row in the bell, under Work finished, linking to `/agents?design=open`; hiring, discarding or replacing the design marks that row read. While a design is generating or waiting for review, the **+** on the roster carries a dot.

The record is as durable as Redis: the stack's Redis keeps RDB snapshots and no append-only log, so a Redis crash, though not a clean stop, can lose a design written in the last minute or so. A design whose api process dies mid-run resumes when the run's lease runs out, up to five minutes later.
