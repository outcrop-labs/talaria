- **Local gates compile only what the diff touches, and cargo is capped at two jobs.** Agents were running `verify` and a workspace `cargo test` / `api:check` before every pull request. That takes an exclusive lock on `api/target` and, uncapped, every core and a matching pile of RAM, so the box they were in — and every other box on the host — stopped responding. `bun run gate` is now the local pre-push gate: `check` always, then typecheck, tests, clippy and `cargo test` only for the surfaces and packages the diff touches. A lockfile or workspace-manifest change is CI's api job, not a local workspace compile. `jobs = 2` in both cargo configs is the CPU cap and the RAM cap (each rustc is a multi-GB process on the same jobserver); CI lifts it with `CARGO_BUILD_JOBS`. Verified: `bun run gate` (check, the cleanup-sweep tests, the gate self-test; desktop fmt, clippy, and tests for the new cargo config; the api compile skipped because this diff only touches `api/.cargo/config.toml`).
