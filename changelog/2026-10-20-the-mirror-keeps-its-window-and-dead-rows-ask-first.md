- **Fixed:** Three smaller MCP registry edges. The marketplace mirror's incremental sync advanced its `updated_since` mark even when the run's time budget cut it off mid-window, so the pages it never fetched were never asked for again (a long outage followed by a catch-up is exactly that case); a cut-off run now keeps the mark and re-asks the window next run — the upsert is idempotent, a skipped page was not. Registering a server whose URL the library's liveness job last found dead now answers 400 with the probe's detail unless the body says `force: true` — the marketplace sends it when the person chose "show unreachable" and picked one. And the Talaria toolkit child (`mcp/dist`) no longer inherits the api's whole environment — the database URL, the secretbox key and every provider credential were in it; it gets what `mcp/src/index.ts` reads plus `PATH`, `HOME` and the `NODE_*` knobs. Verified: `cargo test -p talaria-mcp-library`, `cargo test -p talaria-mcp-service`, `cargo test -p talaria-routes-fleet`, clippy `-D warnings` on each, `bun run check`.
