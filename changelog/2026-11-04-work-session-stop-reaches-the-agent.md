- **Stop on a work session now stops the agent, not just the stream.** Pressing Stop used to mark the run `cancelled` while the agent's tool ran on to the end: dropping the stream does not end a turn in Hermes. Each turn's Hermes run id is now kept on a new `runs.agent_run_id` column, and Stop and the thrash brake both send `POST /v1/runs/{id}/stop` and wait for the agent to report the turn over. Verified on a real session on a real model: during `sleep 65; touch marker`, rc let the tool run 56.5 s after Stop and wrote the marker; with this change the process was gone in 0.3 s, no marker, the agent's transcript reads `[Command interrupted]`, and the route answered in 44 ms against rc's 34 ms.
