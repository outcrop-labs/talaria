- **Stop on a work session now stops the agent, not just the stream.** Pressing Stop used to mark the run `cancelled` while the agent's tool ran on to the end: dropping the stream does not end a turn in Hermes. Each turn's Hermes run id is now kept on a new `runs.agent_run_id` column. The Stop route starts the agent's stop in the background and answers at once; that task sends `POST /v1/runs/{id}/stop` and polls until the agent reports the turn over, for at most 30 s. The thrash brake sends the same stop and waits for it. A Stop that lands while a turn is still opening is not lost: the turn is read on until it names itself, then stopped. Verified on a real session on a real model: during a `sleep N; touch marker` tool, rc let the tool run 56.5 s after Stop and wrote the marker; with this change the process was gone in 0.3 s, no marker, the agent's transcript reads `[Command interrupted]`, and the route answered in 32 ms against rc's 34 ms. A Stop pressed while a turn had no id reached it once the agent resumed, and Hermes reported that turn `cancelled`.
