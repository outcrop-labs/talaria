- **Fixed: loading /knowledge no longer crashes the whole view with `state_unsafe_mutation` when a tree shape is remembered in the tab.** With `talaria:knowledge-tree-state` present in sessionStorage, the tree store hydrated lazily on its first read, and on /knowledge that first read was KbDocRow's `$derived(kbTreeState.docExpanded(...))` or the sidebar's `{#if ... sectionExpanded(...)}` — reactive contexts where Svelte forbids writing state. The hydrate's `store.docs = saved.docs` write threw `state_unsafe_mutation: Updating state inside $derived(...) or a template expression is forbidden` and took the whole knowledgebase view down on arrival; with nothing stored, hydrate wrote nothing, so the crash only appeared for a tab that had opened or closed a branch earlier.
  - `kbTreeState.hydrate()` is now exposed on the store (idempotent, same latch as before) and Knowledge.svelte calls it once at the top of its instance script — a plain statement, before anything renders — so every later `$derived` and template read is a pure read. Nothing else changes: the lazy module-load latch stays, so tests can still install their sessionStorage before the first read.
