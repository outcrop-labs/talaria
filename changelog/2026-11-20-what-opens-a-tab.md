- **Agents are told one rule for what opens a tab in the pane: creating, changing or `open_in_pane` opens a file, and reading never does.** The Work prompt's first sentence said every file the agent "creates or opens" appears as a tab, so an agent that had only read a document with `get_document` told the person it was in their pane. The Work prompt now says a file appears as a tab when the agent creates it, changes it or opens it with `open_in_pane`; that `get_document`, `read_google_doc`, `read_google_sheet`, `read_google_slides`, `read_drive_file` and every search bring a file to the agent, not to the person; that when the person asks to see, open, show, pull up or go through a file the agent calls `open_in_pane`, even for a file it already read; and that a question about what a file says is answered, not opened. "Reading is free" now says reading does not put the file in their pane. The Plan prompt and both Research prompts name every read too, Google reads included, where they named `get_document` alone. In the toolkit, `get_document` and the four Google reads end "Reading does not open it in the person's pane — if they asked to see or open it, call open_in_pane"; `create_document`, `create_sheet` and `create_page` say the file opens in a Work, Plan or Research session's pane by itself; `open_in_pane` lists show and pull up among its asks and names the Google reads among the reads that do not open. The model-fitness catalogue mirrors each description, and the fitness sandbox's `open_in_pane` now answers in the door's shape (`file`, `alreadyOpen`, `theyCanEdit`, `youCanEdit`, `message`, with the door's sentences). The Work-session fitness def gains four fixtures in the owner's words: "Show me …" and "Pull up …" must open the document in the pane without pasting it, "What do … say about retries?" must read it and leave the pane alone, and "Open this Google Doc here: <link>" must open the link with `open_in_pane`'s `url`. The claim that a Google read opens no tab is true once the change that stops Google reads opening tabs is in; until then an agent that follows it makes a redundant `open_in_pane` call, which merges into the tab the read already landed.
