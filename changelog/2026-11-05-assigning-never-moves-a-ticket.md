- **Fixed: assigning a ticket no longer moves it or starts work.** Before, assigning an agent (or a person) to a ticket in intake moved it into the board's agent column ("promoted by assignment") and started the agent on it at once. A ticket created already assigned was born in that column and started straight away too. Now an assigned ticket stays where it is. A new ticket starts in intake unless its creator chooses a column (a new optional `status` when creating, for people; agents' tickets still land in intake). Work starts only when a ticket is in an agent column: a person moves it there, creates it there, or assigns an agent to a ticket already sitting there. Assigning an agent to a ticket anywhere else starts nothing. Agents still move their own tickets while they work, to In progress, Quality review or Blocked, exactly as before. Separately, a person's Stop on an agent now lifts when that person moves the ticket again. It waited for a move recorded under a user id, but the board records a person's moves under their email, so moving the ticket back never lifted it. Tickets an earlier assignment already moved into an agent column stay there; a person can move them back.
