- **Pausing a board's ClickUp sync now freezes it, and the board says who paused it.** Before, Pause held only the schedule: an editor's **Sync now** or a ticket's **Re-sync from ClickUp** still ran and applied ClickUp's changes while the board kept saying "paused". Now nothing reads ClickUp while the sync is paused. The scheduler skips it. **Sync now** and **Re-sync from ClickUp** answer 409 "the ClickUp sync is paused — a board owner resumes it in Board settings → Sync", for owners and editors alike. Pressing **Pause** cancels the run in flight, and a run that raced the pause stops at its next step without moving the watermark. The chip, its panel, the Sync tab and the ticket's re-sync button read "Paused by <name> · <when>", and say who resumes it. A board owner gets **Resume** in the chip's panel as well as on the Sync tab. Still allowed while paused: a mapping change (applied by a remap run that reads nothing from ClickUp), the schedule and options (they take effect on Resume), Replace credential (the sync stays paused), and Disconnect. A mapping or schedule edit saved just as someone presses **Pause** leaves the pause in place: the write takes the state from the row it changes, not from an earlier read. A sync whose token died while it was paused returns to paused, not active, when the token is replaced. A new migration adds `board_syncs.paused_by` and `paused_at`, and the status answers `pausedBy` and `pausedAt`. The generated API reference now lists `paused` on `PUT /api/boards/{id}/sync`.
  - **Workchains: only a close hands a step on.** A sync move into a done column hands a workchain step on, like a person's done. A move into review, Blocked or a working column does not, and starts no successor's agent. A ClickUp close of a ticket in review or Blocked is held. This was already how the code behaved. It is now pinned by a live test and written down in docs/BOARD-SYNC.md.
  - **Smaller fixes.** A sync's activity lines name "ClickUp sync" in place of the raw `clickup-sync` id, on the ticket's Activity tab and in the inbox drawer. At phone width the board's ClickUp chip shrinks with its row: the label truncates, and the chip's colour and problem count stay in view. The board's view switcher (and every small Segmented) and the **Save view** and saved-view buttons no longer drop under a 24px target.
