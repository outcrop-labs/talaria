- **Ticket attachments are a tab.** On the ticket detail, attachments sit
  in an Attachments tab next to Discussion, not in a box under the
  description. The workchain strip and the agent result moved into their own
  tabs (shown only when the ticket has them). The description is a fixed box
  at the top of the view: a long description scrolls inside it, and switching
  tabs does not move or resize it. Verified in the browser on a ticket with a
  long description, an uploaded attachment, and a discussion message —
  description box stayed at the same top and height across Discussion,
  Attachments, and Activity.
